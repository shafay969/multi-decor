## 🌟 Website Features

- **Luxury Multipage Design**: 100% mobile-responsive layout built with modern glassmorphism, gold accents, and fluid typography.
- **Complete Product Catalog (`products.html`)**: Real series profiles (1900, 1800, 1700, 1300, 1000, 200, MM-8262, PU Stone 50mm, Backlit Monoliths, French Moulding) with live category filtering, search, and pre-filled WhatsApp ordering.

- **Smart Wall Panel Estimator Calculator**: Calculates exact panel count, +10% cutting waste buffer, and perimeter trims based on custom wall dimensions.
- **Wholesale & B2B Trade Portal (`wholesale.html`)**: Dedicated portal for architects, interior designers, and general contractors with tier pricing, sample requests, and dealer registration.
- **Project Installations Gallery (`gallery.html`)**: Showcases completed residential and commercial projects in DHA Phase 6, Clifton, Bahria Town, and nationwide.

## 🚀 Running Locally

Open `index.html` directly in any web browser, or launch a lightweight local server:

```bash
# Using Python 3
python3 -m http.server 8008

# Open in browser:
# http://localhost:8008
```
